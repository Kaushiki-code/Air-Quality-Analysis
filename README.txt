AirGuard AI: Machine Learning-Based Air Quality Classification and Pollution Pattern Detection

Files in this folder
1. AirGuard_AI_ML_Project.ipynb        - the main notebook (13 sections)
2. IndianGovernmentAirQualityData.csv  - dataset (must stay in the same folder as the notebook)
3. requirements.txt                    - libraries needed

How to run (Jupyter Notebook)
   pip install -r requirements.txt
   jupyter notebook
   Open AirGuard_AI_ML_Project.ipynb and click Kernel > Restart & Run All

How to run (Google Colab)
   Upload the notebook, then upload the CSV file using the Files panel on the left, then Runtime > Run all
